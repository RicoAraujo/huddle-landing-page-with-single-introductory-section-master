# 💜 Frontend Mentor - Huddle landing page with single introductory section solution

## Huddle Landing Page

Um projeto frontend responsivo do desafio do Frontend Mentor, com uma landing page moderna, limpa e bem estruturada. O layout foi desenvolvido com HTML5 e CSS3, utilizando Flexbox e media queries para garantir uma boa experiência em diferentes tamanhos de tela.

![Huddle Landing Page](./images/project-screenshot.png)

---

## ✨ Funcionalidades

- 📱 **Totalmente responsivo** - funciona bem em desktop, tablet e mobile
- 🎨 **Design moderno** - interface simples e visualmente agradável
- ⚡ **Performance leve** - estrutura organizada e estilos otimizados
- 🔤 **Tipografia elegante** - utiliza fontes do Google Fonts
- 📢 **Call to action destacado** - botão de registro com estilo próprio
- 🔗 **Ícones sociais** - elementos visuais no rodapé
- ♿ **Acessibilidade básica** - uso de semântica HTML e contraste adequado

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** - estrutura semântica da página
- **CSS3** - estilização, responsividade e layout
  - Flexbox para organização dos elementos
  - Media Queries para adaptação em telas menores
- **Google Fonts** - tipografia personalizada
- **Font Awesome** - ícones sociais

O projeto utiliza uma abordagem desktop first, com ajustes para telas menores:

Desktop (acima de 1023px) - layout completo com espaçamento amplo
Tablet/Mobile (até 1023px) - reorganização dos elementos para melhor leitura e visual

## 🚀 Como Executar

1. Clone o repositório:

git clone https://github.com/seu-usuario/huddle-landing-page-with-single-introductory-section-master.git
cd huddle-landing-page-with-single-introductory-section-master

g

2. Abra o projeto no navegador
No Windows: 
start index.html

3. Ou use um servidor local: 
python -m http.server 8000

Depois acesse: 
http://localhost:8000
